## 2. The command

Until cycle 0.0.2's harness exists, a probe is built and run by hand, and `tools/env.sh` holds the four ways this plan
does it, each in one Bash call:

- `run4 <file>` — `npkc`, `llc`, `ld.lld` and the binary, at `-O0` and again through `opt -O2`, printing both exits;
- `stress4 <N> <file>` — the same build, each leg run N times, printing every exit and its count: probes 07 and 08
  have a timing dimension and run forty times (`CONTRIBUTING.md`);
- `codes <file>` — `npkc` alone, printing each diagnostic's code and its `line:col`, which is a refused probe's verdict;
- `bill <file>` — the identities `NITPICK-REACH-003` names for a root that imports the file, what a consumer owes.

What `run4` runs for one probe, written out, from the probe's own directory, with `$NPKC` and `$NPKRT` the pinned
toolchain and `$A` this cycle's gitignored scratch:

```text
$NPKC probeNN_name.npk -o "$A/run4/p.ll"
llc -O0 -filetype=obj -relocation-model=static "$A/run4/p.ll" -o "$A/run4/p.o"
ld.lld -static "$A/run4/p.o" "$NPKRT" -o "$A/run4/p" && "$A/run4/p"; echo "exit $?"
opt -O2 -S "$A/run4/p.ll" -o "$A/run4/p.2.ll"
llc -O2 -filetype=obj -relocation-model=static "$A/run4/p.2.ll" -o "$A/run4/p.2.o"
ld.lld -static "$A/run4/p.2.o" "$NPKRT" -o "$A/run4/p.2" && "$A/run4/p.2"; echo "exit $?"
```

`llc`, `opt` and `ld.lld` are LLVM 20.1.8 — the version the compiler pins since its D-349, asked of the tools
themselves, as block 0a does; the plan's first writing named 20.1.2 (the pin audit's SL-3, carried to 0.0.1).
**Nothing is written under `/tmp`. A probe's exit status is read on its own line**, never through a pipe — the first
writing's command chained `&&` and ended `; echo "exit $?"`, so one printed status stood for whichever command ran last.

## 9. What will bite

- **A keyword cannot name anything** (landing 113): `old`, `result`, `release`, `range`, `pid`, `uid` and `gid` are the
  ones a socket probe reached for first. `specs/BUILD.md` §7 is the table; `tools/names.py` reads every declared name.
- **A name the prelude declares cannot be declared again** — `O_CLOEXEC`, `O_NONBLOCK` and the other `O_*`, `S_*`,
  `MAP_*` and `PROT_*` names are `NITPICK-RESOLVE-001`.
- **`...` is exclusive**, `[a, b)`, in a `for` and a range; `..` is inclusive.
- **A call whose value is `NIL` takes a keyword**: `drop f(x);` for a `never fails` callee, `f(x) ?! E;` for a fallible
  one; and `raw` licenses only a `never fails` callee. A helper that handles every error it meets is declared `never
  fails`.
- **An `async` program's `failsafe` owes `DeadlineExceeded`**, and a reader's owes `IoEof`: each has its code (§6's
  @@PD-163@@). `%` charges `DivByZero` and `DivOverflow`; a parity test is `& 1i64`.
- **An errno compares only with a prelude identity or another error.** A probe identifies one against a witness — a
  syscall known to answer it — and the library never does (@@PD-162@@).
- **Probes 07 and 08 have a timing dimension** and run forty times; one run states a rate, not a verdict.
