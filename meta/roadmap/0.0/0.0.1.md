## 2. Decisions taken at planning

- **P-7 — one placeholder module per directory, and it parses.** An empty
  directory is invisible to the `parse` sweep, and the sweep is what stops the
  grammar being quietly made partial. Each placeholder is
  `src/<dir>/<dir>.npk` with `mod:<dir>;` and a header comment naming the
  specification section that will fill it and the modules it may import
  (`specs/BUILD.md` §6). They are replaced, not deleted.
- **P-8 — `src/lib.npk` re-exports deliberately, one line per public name.**
  `use` is not transitive (`MODULE_REFERENCE.md` §2.3), so the surface is a
  list a reviewer can read in one file.
- **P-9 — the consumer test imports by relative path** (`specs/BUILD.md` B-17)
  and carries a comment naming `O-N2` as the reason, so the day dependency
  roots work, the thing to change is greppable.
- **P-10 — CI pins the compiler by commit**, not by branch. The compiler is
  moving through cycle 1.5; a library whose CI tracks its `main` is a library
  whose CI breaks for reasons that are not its own.
- **P-11 — CI runs the `loopback` stage and skips `network`.** A GitHub runner
  has loopback and IPv6 on `::1`; it does not reliably have outbound
  connectivity worth asserting on. `specs/TESTING.md` V-2's loud skip is what
  makes that visible rather than silent.

## 3. Steps

1. **The module skeleton.** Nine placeholder modules, `src/lib.npk`, and the
   layering comment in each header. Commit.
2. **The consumer.** `tests/conformance/import.npk`: `mod:import;`,
   `use "../../src/lib.npk".*;`, a `main` that exits 0, a `failsafe` with the
   system arms. It compiles against an empty surface, which is the point — it
   keeps compiling as the surface grows, and the day it does not, the surface
   changed incompatibly.
3. **`nitpick.toml`.** The first `[[test]]` entries: `probe` (stage `program`,
   `tests/probe`) and `conformance` (stage `compile`, kind `positive`).
4. **CI.** A workflow that checks out `nsockets`, checks out the compiler at
   the pinned commit, installs LLVM 20.1.2, builds the compiler, and runs
   `harness/run.py` (a stub until 0.0.2, which still must exit 0). On push and
   on pull request.
5. **`CLAUDE.md` and `CONTRIBUTING.md` reviewed.** Both were written at
   repository setup, before the probes ran. This step re-reads them against
   0.0.0's verdicts and extends the reserved-word substitutes and the
   "surprises" list with whatever the probes actually cost.
