## 7. What will bite

- **A short commit in a workflow is a number.** `7e91730` unquoted is infinity in YAML 1.2; every hex value is quoted.
- **`set -o pipefail` and `head`**: a pipeline whose `head` closes its input early can fail on the writer's `SIGPIPE`.
  The workflow's version check reads with `sed -n 1p`, which reads everything.
