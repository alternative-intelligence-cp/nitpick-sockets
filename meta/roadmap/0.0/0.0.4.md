# 0.0.4 — `src/core/` — PLANNED

> **Scope:** `Vec<T>`, `Bytes`, and `limits.npk`. The storage primitives
> `SK-005` decided to own rather than import, plus the one file every named
> bound lives in.

## 1. Decisions taken at planning

- **P-23 — `Vec<T>`'s block is `wild`, its lifetime its owner's scope.** The
  alternative — a managed `buffer` reinterpreted per element — needs a `=>!`
  per access, which is the unchecked reinterpretation the compiler's 1.4.2
  found five latent instances of. One `=>!`, in one file, checked once, is the
  shape that survives. **Every `Vec` has a `vec_free` and every scope that made
  one calls it**, or `exit 0` traps under D-151 — which is exactly the
  enforcement wanted.
- **P-24 — `Bytes` is the only allocating text builder in the library.**
  `string_concat` allocates per call, and address formatting
  (`ADDRESS_MODEL.md` A-23) is otherwise the natural place to write the
  quadratic loop the compiler measured at 17 minutes of a 56-minute run.
- **P-25 — `put_uint` is allocation-free**, writing decimal digits into a stack
  array backwards and appending. Every address format contains numbers and
  `int_to_string` allocates a `string` per call.
- **P-26 — there is no `SmallMap` here.** `ntui` needed one for capability
  overrides; `nsockets` has no lookup table of that shape. A container nothing
  uses is a container nobody tests.
- **P-27 — every accessor's obligation is written now**, in the syntax it will
  take, as a comment, with a property test standing in
  (`specs/VERIFICATION.md` Z-1).

## 2. `Vec<T>`

```nitpick
pub struct:Vec<T> = { wild T->:items; int64:count; int64:cap; };
```

| Function | Contract (a comment now) |
|---|---|
| `vec_init<T>(cap)` | `ensures result.count == 0 && result.cap >= 1` |
| `vec_reserve<T>(v, need)` | `ensures v.cap >= v.count + need` |
| `vec_push<T>(v, move T:x)` | `ensures v.count == old(v.count) + 1` |
| `vec_pop<T>(v)` | `requires v.count > 0` |
| `vec_at<T>(v, i)` | `requires i >= 0 && i < v.count` |
| `vec_set<T>(v, i, move T:x)` | `requires i >= 0 && i < v.count` |
| `vec_truncate<T>(v, n)` | `ensures v.count == min(n, old(v.count))` |
| `vec_clear<T>(v)` | `ensures v.count == 0` |
| `vec_free<T>(v)` | `ensures v.cap == 0 && v.items == NULL` |

**Rule:** `vec_at` returns by value and is therefore for scalar `T` only — for
an owning `T` a copy is refused (TYPE-046), and the family reads through
`v.items[i]` at the site that knows the element's shape. This is the compiler's
own `List<T>` note, and the reason there is no generic `list_at` there either.

## 3. `Bytes`

```nitpick
pub struct:Bytes = { buffer:body; int64:len; };
```

Managed storage — a `buffer`, which drops at scope exit — because a `Bytes` is
per-operation and its reclaim should be automatic. Growth doubles; `take()`
hands the accumulated bytes out as an owned `string`; `view()` hands a borrowed
`uint8[]` for a write path.

## 4. `limits.npk`

Every named bound in one file, each with the specification rule that set it:

```
NSOCK_CMSG_MAX          NSOCK_SCM_MAX_FDS       NSOCK_EMFILE_BACKOFF
NSOCK_POLLSET_MAX       NSOCK_ADDR_MAX          NSOCK_DEFAULT_BACKLOG
NSOCK_CONNECT_TIMEOUT   NSOCK_ACCEPT_TIMEOUT    NSOCK_IO_TIMEOUT
```

`check_constants_named` (0.0.3) enforces that none of these numbers appears
anywhere else.
